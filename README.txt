   js/main.js      ปุ่มเปลี่ยนภาษา, เมนูมือถือ, ฟอร์ม WhatsApp
   css/animations.css  หน้าตาของลูกเล่น/แอนิเมชัน

   js/projects-data.js รายละเอียดโครงการทั้งหมด (ข้อความ + รูป)
   js/projects.js      หน้าต่างรายละเอียดโครงการ (ไม่ต้องแก้)
   css/projects.css    หน้าตาหน้าต่างรายละเอียดโครงการ
   images/projects/    รูปเพิ่มเติมของแต่ละโครงการ
   images/         รูปทั้งหมด

2) วิธีเปิดดู
   แตกไฟล์ zip ก่อน แล้วดับเบิลคลิก index.html
   (ตัวอักษรลาวสวยๆ โหลดจาก Google Fonts ต้องต่ออินเทอร์เน็ต)
   แนะนำให้แก้โค้ดด้วยโปรแกรม VS Code

3) วิธีแก้ข้อความ
   ทุกข้อความมี 2 ภาษาอยู่คู่กัน:
     class="lo"  = ภาษาลาว
     class="en"  = ภาษาอังกฤษ
   ตัวอย่าง:
     <h3 class="lo">ຂົວ</h3><h3 class="en">Bridges</h3>
   แก้ข้อความแล้วต้องแก้ทั้งสองภาษา
   ในไฟล์มีหมายเหตุ <!-- ===== ส่วน: ... ===== --> บอกว่าแต่ละส่วนคืออะไร

4) หัวเว็บและท้ายเว็บ
   หัวเว็บ (เมนู) และท้ายเว็บ (ที่อยู่, เบอร์) ซ้ำอยู่ในทุกไฟล์ทั้ง 6 หน้า
   ถ้าแก้ ต้องแก้ทุกไฟล์ ใช้ VS Code: Ctrl+Shift+H (ค้นหาและแทนที่ทุกไฟล์)

5) เปลี่ยนรูป
   วางรูปใหม่ในโฟลเดอร์ images โดยใช้ชื่อเดิมทับ หรือแก้ชื่อใน src="images/..."
   ช่องที่เป็นกรอบเส้นประ (class="placeholder") คือที่ว่างรอใส่รูป
   เปลี่ยนเป็น: <img src="images/ชื่อรูป.jpg" alt="คำอธิบายรูป">

6) เปลี่ยนสี

11) ลูกเล่นและแอนิเมชัน (อยู่ใน css/animations.css และ js/animations.js)
   1. ข้อความหน้าแรกค่อยๆ ลอยขึ้นตอนเปิดเว็บ
   2. สไลด์รูปหน้าแรก ซูมช้าๆ แล้วเปลี่ยนรูปเอง มีปุ่มขีดมุมขวาล่างให้กดเลือกรูป
      - เปลี่ยน/เพิ่มรูป: index.html ค้นหา class="slide"
      - เปลี่ยนความเร็ว: js/animations.js บรรทัด SLIDE_SECONDS
   3. เนื้อหาค่อยๆ ปรากฏตอนเลื่อนลงมาถึง
   4. ตัวเลข 61, 29, 20+ วิ่งจาก 0 (ใส่ data-count="ตัวเลข" ที่ตัวเลขอื่นได้)
   5. หัวเว็บหดเล็กลงและมีเงาตอนเลื่อน
   6. เส้นกลางถนนสีส้มวิ่ง
   7. การ์ดลอยขึ้นและรูปซูมตอนชี้เมาส์
   8. กดรูปเพื่อดูรูปใหญ่ (หน้าผลงาน, เครื่องจักร, เกี่ยวกับเรา)
   9. ปุ่มลอยมุมขวาล่าง: โทร, WhatsApp, กลับขึ้นบน (แก้เบอร์ในทุกไฟล์ html)
   10. แถบชื่อลูกค้าเลื่อนอัตโนมัติ (หน้าแรก) ชี้เมาส์แล้วหยุด
   - ถ้าเครื่องผู้ชมตั้งค่า "ลดการเคลื่อนไหว" ลูกเล่นจะหยุดเองทั้งหมด
   - อยากปิดลูกเล่นทั้งหมด: ลบ 2 บรรทัดนี้ออกจากทุกไฟล์ html
       <link rel="stylesheet" href="css/animations.css">
       <script src="js/animations.js"></script>
